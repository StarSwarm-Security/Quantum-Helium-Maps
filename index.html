    How the green fill works

    Wallets prove ownership with elliptic-curve signatures. A big enough quantum computer running Shor's algorithm could turn a visible public key into its private key. Nobody can do that yet.

    Each bubble fills from the bottom with an estimated 0 to 100% progress score:

    • Post-quantum migration, up to 50. Live on mainnet 90%, live via contracts 65%, roadmap or testnet 45%, drafts 20%, none found 0.
    • Key exposure, up to 35. Hashed addresses 60%, account model 30%, address is the key 10%.
    • Privacy, up to 15. Private by default 100%, optional shielding 50%, optional mixing 25%, transparent 0.

    Tokens use their host chain's factors. Chains we have not classified show unknown with a dashed ring and no fill. Low scores glow red and float up, higher scores glow green and settle low.

Why do some bubbles glow red?

Crypto wallets prove ownership with a key pair. The private key signs, the public key lets everyone check the signature. Today's chains use elliptic-curve signatures (ECDSA, Schnorr, EdDSA).

A large enough quantum computer running Shor's algorithm could work backwards from a public key to the private key. Nobody can do that yet. The day someone can is called Q-Day.

So the risk depends on how often public keys sit in the open. Some chains use the public key as the address (always visible). Account chains reveal it after your first send. Bitcoin-style hashed addresses hide it until coins move, unless an address gets reused.

The fix is moving funds to post-quantum signatures, which chains will need to add. In the game you are the defender doing that migration before the clock runs out.
